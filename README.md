# co-working-space · SpaceHub

เว็บภาษาไทยสำหรับจองโต๊ะรายที่นั่งหรือห้องส่วนตัวทั้งห้อง ข้อมูลที่นั่งและการจองเก็บใน PostgreSQL บน Neon ส่วนการชำระเงินเป็นเดโมและไม่มีการเรียกเก็บเงินจริง

## จองพื้นที่ทำงาน

1. เปิดหน้าจอง เลือก **รายโต๊ะ** หรือ **ห้องส่วนตัวทั้งห้อง** แล้วเลือกวันที่และรอบเวลา หน้าจองแสดงพื้นที่ว่างและราคาก่อนเข้าสู่ระบบ
2. สมัครหรือเข้าสู่ระบบ แล้วกดจอง ระบบจะกันพื้นที่สูงสุด 30 นาที หรือจนเริ่มรอบหากรอบเริ่มก่อน
3. ตรวจยอดที่หน้าชำระเดโมแล้วกดยืนยัน การจองจะขึ้นเป็น “ยืนยันแล้ว” พร้อมเลขอ้างอิงใน **การจองของฉัน**
4. รายการรอชำระยกเลิกได้ระหว่างที่ยังกันพื้นที่อยู่ รายการยืนยันแล้วยกเลิกได้ถึงวันก่อนเข้าใช้ตามเวลาประเทศไทย เมื่อยกเลิกหรือหมดเวลา พื้นที่จะกลับมาให้คนอื่นจองได้

ใช้เวลา `Asia/Bangkok` และเปิดจองล่วงหน้า 90 วัน มีรอบสองชั่วโมงตั้งแต่ 08.00 ถึง 18.00 น. และรอบเต็มวัน รอบที่เวลาทับกันใช้โต๊ะหรือห้องส่วนตัวเดียวกันไม่ได้ ราคาสำหรับโต๊ะรายที่นั่งคือ 15 บาทต่อโต๊ะต่อรอบ และระบบบันทึกราคาไว้กับการจองแต่ละครั้ง

| ห้อง | โต๊ะตั้งต้น |
| --- | --- |
| ห้องแสงเช้า | 1–20 |
| ห้องร่มไทร | 21–40 |
| ห้องลานฟ้า | 41–50 |

ในโหมดรายโต๊ะ เลือกโซนจากผังย่อแล้วกดหมายเลขบนผังเพื่อเลือกหรือยกเลิกโต๊ะ สามารถเลือกข้ามโซนในรอบเดียวกันได้ ห้องแสงเช้าจัดเป็นแถวคู่ที่มีทางเดินกลาง ห้องร่มไทรแบ่งเป็นกลุ่มโต๊ะหันเข้าหากัน และห้องลานฟ้าจัดเป็นรูปตัวยู ผังเป็นแบบจำลองสำหรับการจอง สถานะว่างอ้างอิงวันและรอบเวลาที่เลือก

กดภาพจำลองข้างชื่อโซนหรือข้างห้องส่วนตัวเพื่อเปิดภาพขนาดใหญ่ การดูภาพแยกจากการเลือกพื้นที่จอง

## เปิดบน Mac

ใช้ Node.js 20 ขึ้นไป รันจากราก repo

```sh
npm ci
npm run build
npm start
```

เปิด [SpaceHub บนเครื่อง](http://localhost:3000) ถ้าต้องการเปลี่ยนพอร์ตให้กำหนด `PORT` ก่อนเริ่มเซิร์ฟเวอร์

โคลนใหม่ที่ยังไม่ได้เชื่อม Neon ให้รันคำสั่งต่อไปนี้จากราก repo ด้วยบัญชีที่เข้าถึงโปรเจกต์ได้

```sh
npm i -g neon@latest
neon init -y --org-id org-green-glade-45544333 --project-id misty-lab-89980545 --branch production --services postgres
neon deploy
```

Neon เขียน `DATABASE_URL` และ `DATABASE_URL_UNPOOLED` ลงใน `.env.local` หรือ `.env` สำหรับโปรเจกต์ที่มีไฟล์นี้อยู่แล้ว แอปใช้ URL แบบ pooled รับคำขอ และใช้ URL แบบ direct จัดการ schema ตอนเริ่มต้น

- กำหนด `ENCRYPTION_KEY` เป็นค่า hex 64 ตัวอักษร สำหรับฐานข้อมูลเดิมให้ใช้คีย์เดิมเพื่ออ่านโปรไฟล์ที่เข้ารหัสไว้
- เมื่อสร้างฐานข้อมูลใหม่ สามารถตั้ง `INITIAL_MANAGER_PASSWORD` เพื่อสร้างผู้จัดการคนแรก `admin@spacehub.co`
- ผู้จัดการเปิด **Reservations & check-in** เพื่อดูคิวและเช็กอินการจองที่ยืนยันแล้วในวันเข้าใช้ รายการรับชำระในแอปนี้เป็นยอดทดลอง
- ระบบออกเซสชันผ่านคุกกี้ HttpOnly เซิร์ฟเวอร์ตรวจเจ้าของการจองจากเซสชันก่อนให้ดู ชำระ หรือยกเลิกแต่ละรายการ

## ทดสอบ

```sh
npm test
npm run build
```

`npm run test:booking` ตรวจการจองทั้งโต๊ะและห้องส่วนตัว เวลาทับซ้อนระหว่างรอบย่อยกับเต็มวัน การชำระเดโมซ้ำ สิทธิ์เจ้าของรายการ การหมดอายุ และการคืนโต๊ะ ผ่าน HTTP กับฐานข้อมูลจริง ให้เริ่มแอปบนฐานข้อมูลทดสอบแยก แล้วกำหนด `BOOKING_TEST_URL` เป็น URL แอปและ `BOOKING_TEST_DATABASE_URL` เป็น URL ฐานข้อมูลเดียวกัน ชุดทดสอบสร้างบัญชีเฉพาะรอบและลบข้อมูลเมื่อเสร็จ

GitHub Actions รันเทสต์และ build ทุกครั้งที่ push หรือเปิด pull request ไปยัง `main` งาน SonarCloud และการเผยแพร่ไป Render ใช้การสั่งรันด้วยตนเองจากแท็บ Actions เมื่อมีการตั้งค่าบริการนั้น
